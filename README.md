# Polite Web Scraper

## Target classification

### Target site

**Site:** Books to Scrape  
**URL:** https://books.toscrape.com/

Books to Scrape is a sandbox website designed for practising web scraping. The
site contains a catalogue of books that can be used as a scraping target.

### Scraping scope

This assignment will scrape only the **first 3 catalogue pages**.

The scraper will collect book information from those pages, including:

- Book title
- Price
- Availability
- Rating
- Book URL

### robots.txt

I requested:

https://books.toscrape.com/robots.txt

The server returned:

`404 Not Found`

No robots found.

The missing robots.txt file is not treated as permission to scrape other
websites. This scraper will remain within the defined scope of this assignment.
